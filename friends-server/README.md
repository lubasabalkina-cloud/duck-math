# FREE SEVER — комнаты для друзей (кандидат, не опубликовано)

Дата: 2026-11-11. Рабочий сайт v20 не изменён.

## Реализовано
- Собственный WebSocket relay: случайный восьмисимвольный код, до четырёх участников, максимум два игрока в каждой команде.
- Командный deathmatch, карты Oasis и Dune; карта фиксируется при создании комнаты.
- Обмен состояниями, выстрелами и попаданиями, проверка принадлежности игроков комнате и команде, ограничение сообщений/размера/очереди, heartbeat и очистка пустых комнат.
- Кандидат интерфейса создания/входа: friends-ui.js.
- Сетевой клиент адаптирован из https://github.com/Kuzmaeth/clutcher/blob/main/multiplayer-client.js, ранее авторизованного пользователем исходного проекта. Удалены внешние серверы по умолчанию и произвольная подмена endpoint через URL. Запуск с ботами не подключается к комнате.

## Проверка
`npm ci && npm test` (Node 22+). Два теста прошли с настоящими локальными WebSocket-соединениями: приглашение, состав, движение, попадание, изоляция комнат, лимиты команд, выход, несуществующая комната, повреждённый JSON, недопустимый Origin.
Это не подтверждает полноценный игровой матч: отображение, респаун, экипировка, счёт и поведение двух браузеров ещё не проверены.

## Размещение
Папку сервера можно разместить отдельным Node Web Service. Render blueprint находится в render.yaml; файлы этой папки должны лежать в корне серверного репозитория. Build: `npm ci`, Start: `npm start`, Health: `/health`, WebSocket: `/ws`. PORT задаёт хостинг. Нужны HTTPS/WSS, один экземпляр сервера, Node 22+.
ALLOWED_ORIGINS содержит точные адреса FREE SEVER. Не указывать `*`.
Состояние комнат хранится в памяти: при перезапуске сервера комнаты закрываются. Это дружеский режим с клиентским расчётом попаданий, не соревновательный сервер с защитой от читов.

## Что остаётся
1. Разместить сервер в аккаунте владельца, получить постоянный WSS URL. Доступа к такому аккаунту сейчас нет.
2. Выложить multiplayer-client.js и friends-ui.js в папку игры и вызвать installFriendsUI(window.game, endpoint, clientScript) после загрузки движка. До получения рабочего адреса live bootstrap не менять.
3. Проверить выбор команд, модели обоих игроков, движение, попадания, смерть/респаун, счёт, выход и переподключение в двух браузерах. Исправить выявленные несовместимости; отдельно проверить Safari/Chrome.
4. Проверить отключение тестовых читов в сетевом матче. Исходная защита игры использует multiplayerActive.
5. Публиковать готовую интеграцию только после проверок; не представлять наличие relay как готовый онлайн-режим.

Bomb Defusal пока не включён: ему необходима отдельная синхронизация раундов, бомбы и общего таймера.
